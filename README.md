##  О проекте

**AR Model Viewer** — учебный проект, направленный на последовательное освоение разработки мобильных приложений на Dart и Flutter.

В рамках лабораторных работ создаётся программная основа будущего приложения для поиска, хранения и просмотра трёхмерных моделей с использованием дополненной реальности.

Разработка ведётся поэтапно: каждая лабораторная работа расширяет существующий проект и добавляет новые компоненты, необходимые для реализации итогового приложения.

На текущем этапе реализована консольная часть на Dart, отвечающая за описание моделей, организацию доступа к данным и поиск объектов по идентификатору.

## Цель проекта

Создать мобильное приложение, которое позволит пользователю:

- Просматривать каталог доступных 3D-моделей.
- Сканировать QR-код и получать идентификатор объекта.
- Находить соответствующую модель по идентификатору.
- Получать информацию о выбранном объекте.
- Просматривать 3D-модели в режиме дополненной реальности.
- В дальнейшем использовать локальную базу данных SQLite для хранения информации.

Перечисленные возможности являются целями итогового приложения. Их реализация будет добавляться в ходе последующих лабораторных работ.

## Выполненные лабораторные работы

### Лабораторная работа №1 — Модель данных приложения на Dart

**Цель:** освоить базовые возможности языка Dart и создать модель данных для описания трёхмерных объектов.

**Реализовано:**

- Класс `ArModel` для хранения информации о 3D-модели.
- Именованные конструкторы для создания объектов.
- Преобразование данных из `Map` с помощью `fromMap()`.
- Коллекция `List<ArModel>` с пятью моделями.
- Поиск объекта по числовому идентификатору.
- Обработка строкового значения QR-кода.
- Безопасное преобразование строки в число с использованием `int.tryParse()`.
- Обработка пустых строк, некорректных значений и несуществующих идентификаторов.
- Дополнительные поля `scale` и `category`.

**Созданные модели:**

| ID | Модель |
|---:|---|
| 1 | Robot |
| 2 | Space Helmet |
| 3 | Planet |
| 4 | Astronaut |
| 5 | Engine |

Назначение дополнительных полей:

- `scale` — масштаб 3D-модели.
- `category` — категория, к которой относится объект.

### Лабораторная работа №2 — Репозиторий объектов

**Цель:** разделить описание данных и способ их хранения, применить принципы объектно-ориентированного программирования и асинхронные операции.

**Реализовано:**

- Перечисление `ArModelType` для типизации моделей.
- Абстрактный интерфейс `ModelRepository`.
- Реализация `MemoryModelRepository` для хранения объектов в памяти.
- Асинхронные методы получения списка и поиска моделей.
- Метод `getAll()` для получения всех объектов.
- Метод `getById()` для поиска по идентификатору.
- Геттер `fileName` для получения имени файла 3D-модели.
- Геттер `typeName` для получения понятного пользователю названия типа модели.
- Именованный конструктор `ArModel.fromMap()` для преобразования данных.
- Функция `parseQrId()` для проверки и преобразования идентификатора QR-кода.
- Функция `findModelByQr()` для поиска модели через интерфейс репозитория.
- Обработка некорректных идентификаторов и отсутствующих объектов.

**Архитектурный принцип**

Клиентский код взаимодействует с моделями через интерфейс `ModelRepository`, не обращаясь напрямую к внутреннему списку объектов.

На текущем этапе используется `MemoryModelRepository`. В дальнейшем его можно будет заменить реализацией на основе SQLite, сохранив общий интерфейс доступа к данным.

## Запуск проекта

### Требования

- Установленный [Dart SDK](https://dart.dev/get-dart).
- Git для получения исходного кода.

### Запуск из исходного кода

1. Клонируйте репозиторий:

   ```bash
   git clone <(https://github.com/Dimasyaaa/ar-model-viewer_DART-FLUTTER)>
   ```

2. Перейдите в папку проекта:

   ```bash
   cd AR-Model-Viewer
   ```

3. При необходимости загрузите зависимости:

   ```bash
   dart pub get
   ```

4. Запустите программу:

   ```bash
   dart run
   ```

Если точка входа проекта находится в другом файле, укажите его путь явно, например `dart run bin/main.dart`.
